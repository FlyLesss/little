# little

1000 美元现金账户的美股科技股日内计划。每天一条结构化记录，只写已经核对过的报价和条件，不成交不记成持仓。

## 数据

- `data/account.json`：资金、每日目标和交易约束
- `data/days/YYYY-MM-DD.json`：当天报价、买卖价、股数、建议、事件、后续关注和预测盈利

`status` 为 `plan_only` 时，文件里的价格是计划，不是成交。`fills` 只有在后续记录核对到真实委托成交后才填写。盘后复核写在 `postCloseReview`，不改当天早上的计划价。

每日盈利目标是 30 美元。这个数字只记在账上，不用它反推卖出价。卖出价用已经出现过的价位。基准预测经常是 0，因为条件不满足就空仓。
